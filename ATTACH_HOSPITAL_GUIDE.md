# 🏥 Прикрепление к больнице (Сохранение в БД)

## 🎯 Что было добавлено

### Backend (`/api/users/`)

#### POST `/attach-hospital`
Прикрепляет пользователя к больнице и сохраняет в БД

**Требует**: Authorization header с токеном
**Тело запроса**:
```json
{
  "hospitalId": "507f1f77bcf86cd799439012"
}
```

**Ответ**:
```json
{
  "success": true,
  "message": "Вы успешно прикреплены к больнице",
  "hospital": {
    "_id": "507f1f77bcf86cd799439012",
    "name": "Городская больница №2",
    "address": "ул. Бейбитшилик, 54",
    ...
  }
}
```

#### GET `/attached-hospital`
Получает информацию о прикреплённой больнице пользователя

**Требует**: Authorization header с токеном
**Ответ**:
```json
{
  "success": true,
  "hospital": {
    "_id": "507f1f77bcf86cd799439012",
    "name": "Городская больница №2",
    ...
  }
}
```

### Frontend

#### Компонент Home (`home.jsx`)
- **Новый раздел**: "🏥 Прикреплённная больница"
- **Поведение**:
  - При загрузке страницы: получает информацию о прикреплённной больнице из API
  - При прикреплении: НЕ перекидывает назад, остаётся на странице
  - При прикреплении: сохраняет в БД через API (не localStorage)
  - При прикреплении: обновляет раздел "Прикреплённная больница" с новыми данными

#### Сервис (`authService.js`)
Добавлены методы:
```javascript
authService.attachHospital(hospitalId)      // POST /users/attach-hospital
authService.getAttachedHospital()           // GET /users/attached-hospital
```

- `.attached-hospital-card` - карточка с информацией
- `.attached-hospital-empty` - пустое состояние
- И другие вспомогательные классы

## 🔄 Поток работы

### Шаг 1: Загрузка страницы
```
Home компонент монтируется
  ↓
useEffect запускает fetchAttachedHospital()
  ↓
authService.getAttachedHospital() вызывает API
  ↓
Backend возвращает информацию о прикреплённной больнице пользователя
  ↓
setConfirmedHospital(response.hospital)
  ↓
Отображается раздел "Прикреплённная больница"
```

### Шаг 2: Прикрепление к больнице
```
Пользователь нажимает на больницу
  ↓
handleSelect(hospital) → выбирает больницу
  ↓
Нажимает кнопку "Прикрепиться к этой больнице"
  ↓
handleOpenModal(hospital) → открывает модаль
  ↓
В модали нажимает "Прикрепиться к этой больнице"
  ↓
handleConfirm() вызывает authService.attachHospital(hospitalId)
  ↓
API /users/attach-hospital сохраняет связь в БД
  ↓
setConfirmedHospital(modalHospital)
  ↓
Модаль закрывается
  ↓
Раздел "Прикреплённная больница" обновляется с новыми данными
```

### Шаг 3: Просмотр информации
```
В разделе "Прикреплённная больница":
  - Название и тип больницы
  - Адрес
  - Рейтинг и количество отзывов
  - Номер телефона (кликабельный)
  - Рабочее время
  - Доступные сервисы
  - Кнопка "Изменить больницу"
```

## 💾 Сохранение в БД

### Принцип
Информация о прикреплённной больнице сохраняется в БД в User модель:
```javascript
User {
  name: String,
  email: String,
  phone: String,
  iin: String,
  hospitals: [ObjectId], // ← Массив ID больниц (одна текущая)
  appointments: [ObjectId],
  ...
}
```

### Обновление БД
При прикреплении:
```javascript
User.findByIdAndUpdate(
  req.userId,
  { hospitals: [hospitalId] },  // Заменяем массив
  { new: true }
).populate('hospitals')
```

## 🔐 Безопасность

### Защита прикрепления:
- Требуется **authMiddleware** (проверка токена)
- Только аутентифицированный пользователь может прикрепиться
- Невозможно прикрепиться от имени другого пользователя

### Данные отправляются:
- Через HTTPS (при production)
- С авторизацией Bearer токена
- К защищённому API endpoint

✅ **Безопасность** - требует авторизацию
